### Level 1 — Create a controller

Which Artisan command generates a new controller named `ReportController`?

<details>
<summary>❌ <code>php artisan make:model ReportController</code></summary>

Not quite! That creates a **model**, not a controller. Try the other option.

</details>

<details>
<summary>✅ <code>php artisan make:controller ReportController</code></summary>

**Correct!** 🎉 You unlocked Level 2.

### Level 2 — Secure the query

Which approach safely binds a user-supplied ID in a database query?

<details>
<summary>❌ <code>DB::select("SELECT * FROM users WHERE id = $id")</code></summary>

Interpolating untrusted input directly into SQL can create an **SQL injection risk**. Try the parameterized query.

</details>

<details>
<summary>🏆 <code>DB::select('SELECT * FROM users WHERE id = ?', [$id])</code></summary>
